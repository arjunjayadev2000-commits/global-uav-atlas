IMPORTANT SCOPE LIMIT
No authoritative, complete worldwide registry of every UAV, FPV design, one-off research
airframe, cancelled prototype, local modification, white-label commercial model, or
battlefield-built drone exists. This package is a consolidated best-effort research database,
not a claim that every drone ever built is included.

PHOTO STATUS
The database includes fields for direct photo URL, source page, licence and photo status.
Direct photographs were not automatically embedded because each image requires identity and
licence verification. A Wikimedia Commons media-search URL is generated for each canonical
record to support the next photo-collection pass.

DATA GOVERNANCE
- Canonical records are deduplicated primarily by normalized platform name.
- Source records are preserved separately for auditability.
- Conflicting origin values are retained in notes.
- Low-confidence records should be checked before publication or operational use.
- Technical fields are stored as text because source units and range notations can contain
  intervals, approximations and missing values.
